Q5 [direct] How do I import a CSV file into Notion?
  expected: import-data.md | status: answered | score: 0.72 | corrected: None
  A: To import a CSV file into Notion, follow these steps:

1. **Open the import dialog**  
   - Go to **Settings → Import → CSV**, **or** type **/csv** in any page.

2. **Upload your CSV file**  
   - Choose the .csv file you want to bring in.

3. **Choose where the data goes**  
   - Select **“Create a new database”** if you want a fresh table, or **“Import into an existing database”** if you already have one.

4. **Select the import location**  
   - Pick the page or workspace where the new database (or the updated one) should appear.

5. **Map CSV columns to Notion properties**  
   - For each column in the CSV, match it to the appropriate Notion property (title, text, number, date, etc.).

**Alternative method (inside an existing full‑page database):**

1. Open the database, click the **•••** menu at the top, and choose **“Merge with CSV.”**  
2. Upload the CSV and then match its columns to the database’s properties.

After completing the mapping, Notion will create the database (or add the rows) with each CSV row becoming a page and each column becoming a property.

Q8 [direct] How do database automations work?
  expected: database-automations.md | status: answered | score: 0.73 | corrected: None
  A: Database automations run whenever a specific change occurs in a database. Each automation is made up of **triggers** (the events that start the automation) and **actions** (the resulting effects). When a change happens, the automation is processed within a three‑second window; if the trigger is removed or the change is deleted within that window, the automation won’t fire. This lets you automatically perform tasks—like assigning a task when its status changes or sending a Slack notification when a new page is added—without manual effort.

Q103 [typo] How do I import a CSV file into Noton?
  expected: import-data.md | status: answered | score: 0.72 | corrected: How do I import a CSV file into Notion?
  A: To import a CSV file into Notion:

1. **Open the Import dialog**  
   - Go to **Settings → Import → CSV**  
   - *(or type `/csv` in any page to start the import)*  

2. **Upload your CSV file** – select the .csv file from your computer.

3. **Choose where the data goes**  
   - Create a **new database**, or  
   - Import the data **into an existing database**.

4. **Select the import location** – pick the page or database where you want the CSV data.

5. **Map the columns** – match each CSV column to the corresponding Notion property you want (e.g., title, date, select, etc.).

**Alternative method (from within a database):**  
While viewing a full‑page database, click the **•••** menu at the top → **Merge with CSV**, then match the CSV columns to Notion properties.
