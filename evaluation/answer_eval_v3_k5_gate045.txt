Q5 [direct] How do I import a CSV file into Notion?
  expected: import-data.md | status: answered | score: 0.72 | corrected: None
  A: **To import a CSV file into Notion:**

1. **Open the Import dialog**  
   - Go to **Settings → Import → CSV** in the sidebar, **or** type **`/csv`** in any page and select the CSV option.

2. **Upload your CSV file**  
   - Click **Upload** and choose the **.csv** file you want to bring in.

3. **Choose where the data goes**  
   - Decide whether to **create a new database** or **import the data into an existing database**.

4. **Select the import location**  
   - Pick the page or database where the new data should appear.

5. **Map the columns**  
   - For each CSV column, match it to the appropriate Notion property (e.g., Title, Text, Number, etc.).  

   - Confirm the mappings and finish the import.

**Alternative method (if you’re already inside a database):**

1. While viewing a full‑page database, click the **•••** (three‑dot) menu at the top.  
2. Choose **“Merge with CSV.”**  
3. Upload the CSV and map its columns to the existing database’s properties.

After completing these steps, the CSV rows become Notion pages and the columns become properties in the database.

Q8 [direct] How do database automations work?
  expected: database-automations.md | status: answered | score: 0.73 | corrected: None
  A: Database automations are sequences of actions that run whenever a specific change occurs in a database. They consist of **triggers** (the events that start the automation) and **actions** (what the automation does). When a change happens, the automation operates within a three‑second window—if the trigger is removed or the change is deleted within that time, the automation won’t fire. You can set an automation to run on pages in the entire database or only on pages that appear in a particular view (and it will adjust if the view’s filters change). Automations are created via the ⚡ button at the top of a database, where you add triggers and actions, then save the automation. Guests with full access cannot create automations.

Q9 [direct] How can I set a reminder in Notion?
  expected: reminders.md | status: answered | score: 0.77 | corrected: None
  A: To set a reminder in Notion, you can:

1. **Use the @‑remind command**  
   - In any page, type `@remind` followed by the date and time you want to be reminded, then add the reminder text.  
   - Example: `@remind tomorrow 9 am to submit the report`.

2. **Add a reminder via a Date property (in a database)**  
   - Click the **Date** property for the page or database item.  
   - In the calendar window that opens, set the date, choose a specific time, and specify how far in advance you want the reminder (e.g., 30 minutes before).  

3. **Remind someone else**  
   - Combine an @‑mention with @‑remind on the same line.  
   - Example: `@Camille Ricketts @remind next Thursday 4 pm to finish proofreading`.

When the reminder time arrives, Notion will send you (or the mentioned person) a notification.

  expected: whos-who-in-a-workspace.md | status: answered | score: 0.64 | corrected: None
  A: A **restricted member** is a type of teamspace member who is given a broader level of access to the workspace—such as the ability to interact with all pages in a teamspace and to use Notion AI (with AI respecting their permissions).  

**How they differ from regular members**

- **Access level**: A restricted member can be granted broader workspace access, while a regular member has the standard level of access.  
- **Permission hierarchy**: The teamspace member role includes both regular and restricted members, meaning a restricted member cannot be given a lower level of access than a regular member. If you need to give a restricted member a lower level of access, you must do so through permission groups or individual permissions.  
- **Management controls**: Restricted members are managed via specific settings (e.g., who can add them to teamspaces or pages) and can be added when you need broader access or AI usage, whereas regular members are added without those extra controls.
